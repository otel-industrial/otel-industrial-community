# OpenTelemetry Industrial Introduction to Margo

**Date:** July 30, 2026

This folder contains the presentation delivered to the Margo community introducing the OpenTelemetry Industrial initiative.

## About Margo

Margo is an open source project focused on building an interoperable edge platform for industrial automation.

- Website: https://margo.org

## Overview

The presentation covers:

- Introduction to OpenTelemetry Industrial
- Community goals and vision
- Current ecosystem and ongoing projects
- OpenTelemetry Collector support for industrial protocols
- Industrial semantic conventions
- Opportunities for collaboration between the Margo and OpenTelemetry Industrial communities
- How to get involved
